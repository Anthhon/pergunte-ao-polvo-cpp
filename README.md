# pergunte-ao-polvo-cpp

![Pergunte ao Polvo CPP Screenshot](./screenshot.png)

## Como usar

- Clone o repositório
- Compile os manuscritos da entidade em C++
- Hospede um canalizador de energias para a manifestação do Polvo na sua máquina
- Entre em contato

```bash
# Clona o repositório
git clone git@github.com:Anthhon/pergunte-ao-polvo-cpp.git
# Entra na pasta do projeto
cd pergunte-ao-polvo-cpp
# Força o projeto a compilar
make -B
# Hosteia o API da aplicação (Obs.: 8080 pode ser trocado por uma outra porta)
./polvo-cpp 8080
# Abre a página conectada a API
xdg-open index.html
```
